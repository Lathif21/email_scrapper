# blocklist.txt — hosts that cannot structurally publish a direct contact.
#
# One domain per line, '#' for comments. Matching is on host suffix at label
# boundaries, so `trip.com` catches `id.trip.com` but not `nottrip.com`.
#
# This is NOT a quality filter. Every entry is here because the site's business
# model or purpose makes a direct company contact impossible to find on it — an
# OTA exists to be the intermediary, a social profile is not a company website.
# Do NOT add a domain just because its results were disappointing, and do NOT
# grow this file automatically from run output: legitimate sites get dropped
# that way.
#
# Disable entirely with --no-blocklist, or point elsewhere with --blocklist PATH.
